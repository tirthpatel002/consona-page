# Page previews

`ChildPagePreviews({registry, pages, blobs?, parentId, version?, onOpen, excludeIds?})` derives child IDs from the page registry. `PagePreview({registry, pages, blobs?, pageId, parentId?, version?, onOpen})` resolves one reference. Neither writes a body or mounts an editor. A parent holds no duplicate child content.

`createPagePreviewPlugin(host)` from `./plugin` adds an in-body **Page reference** embed. Its validated props are `{pageId: string}` only. The initial empty block offers a searchable page picker while editable. When read-only it offers no picker. The host supplies `{registry, pages, blobs?, pageId: () => currentPageId, onOpen}`. This is an app navigation callback, not a URL from persisted content.

Rendering is clipped to a fixed top-height region and bounded to 12 top-level blocks, 120 nodes, 8 nesting levels and 4,000 text characters. Pass `excludeIds: ReadonlySet<string>` to omit children already referenced explicitly in the body. Exclusions are applied before the 50-preview limit and update immediately when props change; the explicit reference is not changed. Up to 50 remaining child previews are listed; the sidebar retains all children. The preview body is inert and hidden from assistive technology; the title is a real Open button. Links inside the preview cannot activate. Existing validated embed renderers run read-only, except page references which render as a passive label to prevent recursive trees. Oversized embed props fall back to a label. Native text, headings, lists, tables, columns and cards render without an editor. Stored raster images resolve with the supplied blob store and their object URLs are revoked on unmount. Video, audio, embeds, files and remote images are labelled placeholders; no external media request or autoplay happens when a parent opens. Inline raster images may render. A preview does not fetch an iframe or execute imported HTML.

Missing, self-referencing and trashed pages (including under a trashed ancestor) are not opened by the preview. Store failures show retry rather than a fake empty body. Locks do not hide readable content; previews never modify locked pages. `pages.subscribe` refreshes saved body changes. Pass a changed `version` when registry titles/moves/trash change; registry adapters currently have no subscription contract. The host owns navigation and cross-tab registry refresh.
